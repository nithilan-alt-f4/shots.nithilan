# Browser Homepage Design Direction

## Three stylistic approaches

### Theme Name: Quiet Command Deck
Very dark, cinematic, and tactile: a personal desktop cockpit that makes utility feel calm and intentional.

Probability: 0.03

### Theme Name: Paper Orbit
Warm editorial surfaces, cut-paper layers, and a playful modular canvas for daily links and widgets.

Probability: 0.07

### Theme Name: Signal Garden
A daylight-forward ambient homepage with soft color fields, organic weather motion, and gentle discovery.

Probability: 0.05

## Chosen Direction: Quiet Command Deck

### Design Movement
Cinematic editorial interface design with restrained neo-brutalist utility and translucent desktop layers.

### Core Principles
- Make the browser feel like a personal instrument panel rather than a generic start page.
- Use strong contrast and generous negative space so information can be scanned instantly.
- Treat widgets as movable objects with visible handles, material surfaces, and purposeful density.
- Keep customization close at hand without turning the experience into a settings dashboard.

### Color Philosophy
The foundation is deep slate pulled from a moonlit landscape, with warm ivory for readable type and a single coral signal color for actions and focus. The palette should feel nocturnal and grounded; coral is reserved for “change,” “add,” and active states so it remains ownable.

### Layout Paradigm
An asymmetric command canvas: the clock and weather occupy the left visual anchor, while a slim right rail holds the control palette. Shortcuts and widgets float in a loose field rather than a centered card grid.

### Signature Elements
- Thin coral “signal” rules that mark active controls.
- Translucent graphite panels with a subtle grain texture.
- Small uppercase labels and coordinate-style metadata for a crafted instrument feel.

### Interaction Philosophy
Everything should feel adjustable but safe. Changes preview immediately, controls stay within one click, draggable objects respond with a slight lift, and destructive actions are avoided in favor of reversible toggles.

### Animation
Use short 180–260ms ease-out transitions for controls and panel reveals. Draggable widgets lift with a modest translateY and shadow increase. Avoid constant motion except for a faint ambient glow in the weather marker and a soft clock tick.

### Typography System
Use Space Grotesk for expressive display numerals and headlines, and IBM Plex Mono for metadata, labels, shortcut URLs, and control copy. Headlines use tight tracking; utility copy uses compact uppercase mono with increased letter spacing.

### Brand Essence
A quietly powerful start page for people who want their browser to feel like theirs — focused, configurable, and atmospheric.

Personality: composed, tactile, precise.

### Brand Voice
Headlines are direct and slightly poetic. CTAs are verbs with a point of view. Microcopy explains what changed rather than filling space.

Example lines:
- “Make the first tab yours.”
- “Drag a widget into the day.”

### Wordmark & Logo
The mark is a rounded browser window fused with a four-point compass star: a small navigation instrument for the open web.

### Signature Brand Color
Signal Coral — `#ff725c`.
