# Customization extension checklist

- [ ] Add local image upload for replacing the wallpaper, with browser persistence and a reset option.
- [ ] Add custom right-click menus for the canvas, bookmark group, individual bookmark, widgets, and wallpaper.
- [ ] Add bookmark appearance controls for layout, text alignment, icon size, labels, and spacing.
- [ ] Use website logos for bookmarks through a static-compatible logo URL with graceful fallback.
- [ ] Remove the footer and the “Drag any panel by its empty space or handle” hint.
- [ ] Verify desktop rendering, context-menu behavior, upload behavior, and no compile errors.
